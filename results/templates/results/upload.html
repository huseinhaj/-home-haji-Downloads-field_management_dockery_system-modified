{% if LANG == 'sw' %}Mtiririko wa Mfumo{% else %}How It Works{% endif %}

{% if LANG == 'sw' %}
  1. Academic anaunda mtihani na kuweka masomo (hapa)
  2. Mwalimu wa kila somo anaingia Marks Entry → anapakia orodha ya wanafunzi, anajaza alama → "Hifadhi & Kagua"
  3. Mfumo unazalisha PDF ya somo lake moja kwa moja
  4. Mbadala: Mwalimu anaweza upload file badala ya kujaza moja kwa moja
  5. Academic anaona masomo yaliyokamilika → anabonyeza "Zalisha Matokeo ya Mwisho"
  6. Mfumo unazalisha Excel ya kitaalamu na wanafunzi wote, masomo yote, position, division
{% else %}
  1. Academic officer creates the exam and sets up its subjects (here)
  2. Each subject's teacher opens Marks Entry → uploads the student list, enters scores → "Save & Review"
  3. The system generates that subject's PDF instantly
  4. Alternative: a teacher can upload a file instead of entering manually
  5. Academic officer sees which subjects are complete → clicks "Generate Final Results"
  6. The system generates a professional Excel with all students, subjects, position, and division
{% endif %}
